# MindEducation - Образовательная игра для изучения истории Древнего Рима

## Описание проекта

MindEducation - это интерактивная образовательная игра, созданная для изучения истории Древнего Рима, Афин и Крита. Игра предназначена для детей и подростков, предлагая увлекательный способ изучения истории через игровой процесс.

## Особенности

- 🎮 **Интерактивный геймплей** - изучение истории через игру
- 👥 **Два персонажа** - мальчик Марк (12 лет) и девочка Луция (6 лет)
- 🏛️ **Три исторические локации** - Древний Рим, Афины и Крит
- 📚 **Обучающие этапы** - структурированное изучение материала
- 🎯 **Система заданий** - викторины, квесты и интерактивные элементы
- 🎨 **Современный интерфейс** - адаптивный дизайн с анимациями
- ⚙️ **Админ панель** - удобное управление контентом

## Технологический стек

- **Backend**: Spring Boot 3, Java 21
- **База данных**: PostgreSQL 15
- **Frontend**: Thymeleaf, Bootstrap 5, JavaScript
- **Контейнеризация**: Docker, Docker Compose
- **Сборка**: Maven

## Быстрый старт

### 🚀 Способ 1: Локальный запуск (РЕКОМЕНДУЕТСЯ)

1. Убедитесь, что у вас установлены:
   - Java 21 или выше
   - Maven 3.9+ (опционально)

2. Запустите приложение:
```bash
# Windows
run-local.bat

# Linux/Mac
./run-local.sh

# Или вручную
mvn clean package
java -jar target/*.jar
```

3. Откройте браузер: http://localhost:8080

### 🐳 Способ 2: Docker (если локальный запуск не работает)

1. Запустите с исправленным Dockerfile:
```bash
docker-compose up --build -d
```

2. Откройте браузер: http://localhost:8080

### ⚠️ Если возникают проблемы с Docker

См. файл `DOCKER_TROUBLESHOOTING.md` для подробных инструкций по устранению проблем.

### 🔧 Локальная разработка

1. Установите Java 21 и Maven
2. Создайте базу данных PostgreSQL (опционально - приложение создаст H2 в памяти)
3. Запустите: `mvn spring-boot:run`

## Использование

### Игровой процесс

1. **Выбор персонажа**: Выберите между Марком (12 лет) или Луцией (6 лет)
2. **Выбор локации**: Исследуйте Древний Рим, Афины или Крит
3. **Прохождение этапов**: Изучайте историю через интерактивные задания
4. **Выполнение заданий**: Отвечайте на вопросы викторин и выполняйте квесты

### Админ панель

Доступна по адресу: http://localhost:8080/admin

- **Управление персонажами**: Создание и редактирование персонажей
- **Управление локациями**: Добавление новых исторических мест
- **Этапы обучения**: Создание обучающих модулей и заданий

## API Endpoints

### Игровые страницы
- `GET /game` - Главная страница игры
- `GET /game/location/{id}` - Детали локации
- `GET /game/stage/{id}` - Детали этапа обучения
- `GET /game/character/{id}` - Детали персонажа

### Админ панель
- `GET /admin` - Главная админ панель
- `GET /admin/characters` - Список персонажей
- `POST /admin/characters` - Создание/обновление персонажа
- `GET /admin/locations` - Список локаций
- `POST /admin/locations` - Создание/обновление локации
- `GET /admin/stages` - Список этапов обучения
- `POST /admin/stages` - Создание/обновление этапа

## Разработка

### Добавление нового персонажа

1. Перейдите в админ панель: http://localhost:8080/admin/characters/new
2. Заполните форму с данными персонажа
3. Сохраните изменения

### Добавление новой локации

1. Перейдите в админ панель: http://localhost:8080/admin/locations/new
2. Заполните информацию о локации
3. Добавьте исторический период и описание

### Создание этапа обучения

1. Перейдите в админ панель: http://localhost:8080/admin/stages/new
2. Выберите локацию для этапа
3. Заполните детали этапа и задания
