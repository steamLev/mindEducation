## 🚀 Запуск проекта

### Быстрый запуск (Docker):
```bash
# Windows
start.bat

# Linux/Mac
./start.sh
```

### Ручной запуск:
```bash
docker-compose up --build -d
```

### Доступ к приложению:
- **Игра**: http://localhost:8080
- **Админ панель**: http://localhost:8080/admin
